## What this was

Answered how a non-UI/UX designer can get a good web app design for a production SaaS.

## Recommendation

Use a practical design stack instead of trying to become a designer from scratch:

1. Pick 3 to 5 real product references.
2. Use a proven component system such as shadcn/ui, Radix, Mantine, or MUI.
3. Start from the core workflow, not a landing page.
4. Create a small design system: colors, typography, spacing, buttons, forms, cards, alerts, tables, empty states.
5. Validate with screenshots, mobile checks, accessibility, and real user task completion.

## Fit for StoryForge

StoryForge should prioritize a quiet, trustworthy, productivity-focused SaaS interface:

- Clear BRD input.
- Persistent analysis/workspace layout.
- Strong information hierarchy for gaps, questions, score, and PRD output.
- Minimal decoration.
- High contrast and readable Bahasa Indonesia copy.

## Useful Sources

- shadcn/ui / Radix-style component systems for React SaaS apps.
- Figma UI kits for early structure.
- SaaS and dashboard inspiration libraries for reference gathering.
- AI design tools only for first drafts, never as final authority.
